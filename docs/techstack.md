# Project Tech Stack

## Core Architecture & Frontend

- **Frontend Framework:** React with TypeScript (Fast component-based development, strong type safety)
- **Styling:** Tailwind CSS (Rapid UI styling for admin dashboards and subscriber portals)

## Backend & API

- **Backend Runtime:** Node.js with Express and TypeScript (Lean, rapid development environment for API routes)
- **API Architecture:** RESTful API design

## Database & Data Management

- **Database:** PostgreSQL (Robust relational model for user records, roles, locations, and alerts)
- **ORM:** Prisma ORM (Type-safe database client and straightforward migration management)

## Authentication & Security

- **Auth Strategy:** JSON Web Tokens (JWT) and bcrypt (Role-based access control for 3 admin tiers and subscriber Google OAuth)

## Messaging & Communication

- **SMS Integration:** Twilio API (Core telecommunications service for emergency broadcast alerts)

## Testing & Quality Assurance

- **API & Unit Testing:** Jest and Supertest (Validating backend endpoints and core business logic)
- **Local Endpoint Testing:** VS Code REST Client (`requests.http` files version-controlled in the repository)

## Infrastructure, DevOps & Version Control

- **Version Control:** Git & GitHub (Branching workflows, pull requests, and code reviews)
- **Deployment Platform:** Render or Railway (Streamlined cloud deployment for student project delivery)
- **CI/CD:** GitHub Actions (Automated build and test pipelines)
